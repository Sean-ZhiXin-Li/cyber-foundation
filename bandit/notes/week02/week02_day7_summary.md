# Week2 day7 - Summary

## 1. Tools Learned

- grep, find, sort, uniq: searching and filtering information efficiently
- Bash scripting: automating repetitive commands.
- Vim: editing files in terminal, useful for remotes servers.
- Git: version control, engineering traceability, reproducibility

## 2. Core Thinking Patterns

Week2 taught me the problem-solving workflow:

Problem
↓
Analyze conditions
↓
Transform data/files/commands
↓
Filter / extract
↓
Useful information

Examples:

- Bandit 5-7: file properties -> find -> cat -> password
- Bandit 8-10: duplicate/binary/encoded data -> sort/uniq/strings/base64 -> extract -> password
- Shell/Bash: log/file -> grep/awk -> automation -> processed output

## 3. Engineering Connections

Skills learned apply to:

- Linux Engineering: log analysis, server debugging, CI/CD pipelines
- Security/CTF: rapid info extraction, research, password location
- Research/AI projects: data extraction, metric analysis, experiment reproducibility
- Lab Readiness: survive in remote environments, debug systems, track changes

## 4. Biggest Lessons

1. Commands themselves are tools, but thinking is more important.
2. Automation and scripting reduce repetitive work.
3. Traceability via Git ensures reproducibility and debugging capability.
4. Transforming and filtering data is a general skill across Linux, CTF, and research.
